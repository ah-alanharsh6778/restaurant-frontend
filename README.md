Modern Enterprise Restaurant Management System frontend built with **React**, **Vite**, **Material UI**, **Axios**, and integrated with the RestaurantOS REST API.

The application provides a responsive, enterprise-grade user interface for restaurant operations including authentication, dashboard analytics, restaurant tables, orders, menu management, AI invoice processing, inventory, reports, and role-based access control.

# 🔗 Backend Integration

The frontend consumes REST APIs provided by the RestaurantOS backend.

Integrated modules include:

- Authentication
- Dashboard
- Users
- Customers
- Suppliers
- Restaurant Tables
- Menu
- Orders
- Payments
- Expenses
- Inventory
- AI Invoice Processing
- Reports

No mock or hardcoded data is used. All data is loaded from backend APIs.
